# SkillSwap

SkillSwap is a peer-to-peer skill exchange platform designed for college students. 
It helps students connect with others to teach the skills they know and learn the skills they need.

## Problem Statement

Students often have useful skills they can teach others, but there is no simple platform where they can find someone who wants to learn their skill while offering a skill they want to learn.

## Solution

SkillSwap provides a simple platform where students can:

- Create their skill profile
- Add skills they can teach
- Add skills they want to learn
- Find students with matching skills
- Send and accept skill-swap requests
- Chat with matched students
- Give ratings and reviews

## Key Features

- 👤 Student Profile
- 🧑‍💻 Teach & Learn Skills
- 🔍 Skill Search
- 🤝 Skill Matching
- 📩 Swap Requests
- 💬 Student Chat
- ⭐ Ratings & Reviews
- 💾 Data Persistence

## Data Storage

SkillSwap uses:

- **Firebase Cloud Firestore** for storing user profile and skill data.
- **LocalStorage** for maintaining application state and persistence during the prototype/demo.
